# POPCORE Clover sandbox sync companion

This Android app listens for local Clover order changes and sends full, allowlisted order snapshots to the isolated POPCORE sandbox probe. It never writes orders or payments. Clover cloud data remains the source for confirmed payments.

## Build and pair

Open this directory as an Android Studio project and build the `app` debug variant. It uses the official `com.clover.sdk:clover-android-sdk:334` dependency from Maven Central and Gradle 9.4.1 with Android Gradle Plugin 9.2.0. The source tree does not contain downloaded dependencies or a Gradle wrapper executable; use a local Gradle installation or generate a wrapper before a CLI build.

Clover grants **Read Orders** only to an app it installed itself: upload a release APK under the app's **Android APKs** in the sandbox developer dashboard, then install the app on the test merchant, and the emulator's App Updater installs that APK. Clover accepts only the V1 (JAR) signature, so the release build signs V1-only from an ignored `.local/clover-android/keystore.properties` (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`); every later upload or sideload must use that same keystore. Build with `gradle :app:assembleRelease` (the cached Gradle 9.4.1 distribution plus Android Studio's bundled JDK work from the command line). A sideloaded debug build must be uninstalled first, since its signature differs.

The application ID is `ca.popcore.cloversync.sandbox` (Clover rejected `ca.popcore.cloversync` as already in use), while the Java package stays `ca.popcore.cloversync`. For emulator scripting, `am start -n ca.popcore.cloversync.sandbox/ca.popcore.cloversync.MainActivity --es endpoint <url> --es merchant <id> --es secret <key> --ez autostart true` fills the pairing fields and starts sync. The probe URL may be plain HTTP only to `127.0.0.1` or `10.0.2.2` (for a local probe behind `adb reverse tcp:5055 tcp:5055`); anything else must be HTTPS. Configure the probe's private `DEVICE_BRIDGE_ID` with the UUID displayed in the app, and `DEVICE_BRIDGE_SECRET` with a random key at least 32 characters long. Enter the probe's exact sandbox merchant ID and that key in the app, then tap **Start device sync**. Keep its foreground service running while testing. The key is stored in Android app-private preferences and is not embedded in the APK. The default destination is `https://popcore.store/clover-sandbox/device-snapshot`; the setup screen's **Probe URL** field overrides it.

The emulator must have a Clover merchant account and order service available. A debug APK built and installed on the sandbox emulator on 2026-09-28, and the local listener registered. Order callback, local read, bridge delivery, and phone timing remain unverified until the paired sandbox release. The app stops if an order's local merchant does not match the paired sandbox merchant. A rejected pairing stops the service and shows an HTTP status; connection failures retry with the newest pending snapshot. Up to five observed orders are reread every two seconds to recover from missed callbacks and process restarts. Each user-started sandbox sync session stops after six hours, including if Android restarts the service. Tap Start to begin another session. This companion is for short sandbox timing sessions, not all-day store use. Orders deleted on Clover and complex pricing are outside this rehearsal; verify them directly in Clover.

For the pure Java coalescing check, run `javac -d .local/clover-android-test android/clover-sync/app/src/main/java/ca/popcore/cloversync/PendingOrders.java android/clover-sync/app/src/test/java/ca/popcore/cloversync/PendingOrdersTest.java` from the repository root, then `java -cp .local/clover-android-test ca.popcore.cloversync.PendingOrdersTest`.
For the session cutoff check, run `javac -d .local/clover-android-test android/clover-sync/app/src/main/java/ca/popcore/cloversync/SyncSession.java android/clover-sync/app/src/test/java/ca/popcore/cloversync/SyncSessionTest.java`, then `java -cp .local/clover-android-test ca.popcore.cloversync.SyncSessionTest`.
